# YASHIRIN

Места Узбекистана, о которых мало говорят. Сайт-каталог с личными находками автора. Публичный адрес: https://yashirin.netlify.app/

## Структура

- `site/` рабочая версия сайта. `npm test`, `npm run dev`, `npm run build`.
- `archive/` прошлые версии. Не редактировать.
- `docs/backlog.md` все действия по шагам со статусами.
- `docs/decision-log.md` журнал решений с основаниями.
- `docs/chatgpt-review-2026-09-06.md` разбор правок ChatGPT.
- `docs/yashirin-site-analysis.md` разбор glass-версии от 6 сентября.
- `docs/chatgpt-2026-09-06/` отчёты ChatGPT: SWOT, аудит Netlify, план пилота.
- `docs/sources/` исходные документы владельца в тексте, лонглист мест, логотипы.
- `CHANGELOG.md` история изменений сайта.

## Правила работы

1. Один источник правды: этот репозиторий. Любая версия сайта от ChatGPT попадает сюда отдельным коммитом до правок.
2. ChatGPT: тексты, исследования, черновики. Claude: код, проверка, деплой. Владелец: факты, фото, решения.
3. Каждое решение записывается в `docs/decision-log.md`, каждое действие в `docs/backlog.md`.
4. Не обещать на сайте того, чего нет: скидок без договора, событий без даты, фактов без даты проверки.
