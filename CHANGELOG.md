# CHANGELOG

Что менялось в репозитории и на сайте. Новое сверху. Формат: дата, версия, автор изменения, что сделано.

## 2026-09-06 · v0.3.0 · Claude, рабочая версия для Netlify

Структура и роутинг ChatGPT сохранены, поверх возвращён визуал glass и содержание карточек.

- Дизайн: тёмная glass-тема, Unbounded, Golos Text, Playfair Display самохостом (6 файлов woff2, кириллица и латиница, ~130 КБ), янтарный акцент, карточки-фото с glass-панелью, приветствие по времени суток.
- Карточки: возвращены расстояние и время от Ташкента, сезон, пешая часть, таблица «Перед поездкой» с пометкой «сведения на сентябрь 2026». Описания переписаны: что это, зачем ехать.
- Формы: Netlify Forms (`feedback`, `suggest`) с honeypot, отправка без перезагрузки, экран «Спасибо». Если отправка не удалась, показывается текст для Telegram. Добавлено необязательное поле контакта.
- Аналитика: Яндекс Метрика с целями place_view, place_save, map_open, map_all, share, telegram_click, instagram_click, feedback_sent, suggest_sent. Выключена, пока `CONFIG.metrikaId` пуст.
- Шэринг и установка: og.jpg 1200×630, og:url, canonical, manifest.webmanifest, иконки 192 и 512, robots.txt, sitemap.xml, viewport-fit=cover.
- Категории с запасом: горы, у воды, еда, необычное, город. Фильтры показываются только там, где есть места.
- Удалён экспериментальный WebMCP-блок. Счётчик «Сохранённое» скрыт при нуле.
- CSP: form-action 'self', font-src 'self', хосты Метрики. Cache-Control: no-cache для страниц, неделя для assets, год для шрифтов.
- Тесты: 13 (было 8). Сборка копирует все статические файлы. Dev-сервер отдаёт всё, кроме служебного.
- `netlify.toml` в корне: publish = site, перед деплоем запускаются тесты.

## 2026-09-06 · v0.2.0-chatgpt · ChatGPT, положено в репозиторий Claude

Полная переработка сайта, не правка glass-версии. Новая база в `site/`.

- Позиционирование «Места Узбекистана, о которых мало говорят», каталог первым экраном.
- Удалены: анонс выезда, промокод YASHIRIN10, Rent Motors, Instagram travelguide2711, профиль, категории «Необычное» и «Еда».
- Добавлены: хэш-роутинг `#/place/id` `#/saved` `#/about` `#/feedback` `#/suggest`, 404-экран, кнопка «Поделиться», счётчик сохранённого в меню, экран «О проекте», skip-link, aria-атрибуты, noscript, обработка недоступного localStorage, заголовок страницы по маршруту.
- Формы: «Подготовить текст» с предпросмотром, кнопки «Скопировать» и «Открыть Telegram».
- Код разделён: `core.js` данные и функции, `app.js` DOM. 8 автотестов, `npm run dev`, `npm run build`.
- CSS переписан: Arial, одна колонка на телефоне, текст 16 px. Google Fonts убраны.
- CSP ужесточён: `form-action 'none'`, `img-src 'self'`, без `font-src`. Cache-Control не задан.
- Экспериментально: регистрация WebMCP через `document.modelContext`.
- Не изменено: фото, отсутствие аналитики, отсутствие og:image, robots, sitemap, manifest.

Опубликовано ChatGPT на chatgpt.site в режиме owner-only. На Netlify не выкладывалось.
