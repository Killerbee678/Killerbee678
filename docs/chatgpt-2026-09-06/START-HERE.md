## С чего начать
Основная версия для дальнейшей работы: website-source/. Готовая статическая сборка: website-ready/ и отдельный архив Yashirin-site-ready.zip.
Это улучшенная версия, ранее опубликованная в Sites. Она НЕ совпадает со старой публичной версией https://yashirin.netlify.app/.
Не переносите старые обещания скидки и автомобильное позиционирование обратно в основную версию.

## Что внутри
- website-source/: исходники, фотографии, стили, сценарии сборки и тесты.
- website-ready/: файлы сайта для статического хостинга; index.html лежит в корне этой папки.
- reports/: большой SWOT, аудит Netlify и план пилота на 14 дней.
- original-materials/: исходные документы, таблица мест, изображения и прежние архивы сайта.
- research/: материалы исследования, источники, промежуточные результаты и снимок HTML/CSS/JS Netlify на дату аудита. Снимок Netlify — свидетельство для аудита, не полная автономная копия сайта.

## Работа с исходниками
Нужен Node.js. Зависимостей npm нет.
В website-source/: npm run dev — локальный просмотр; npm test — проверки; npm run build — сборка в dist/.
При дальнейших изменениях заново собрать и проверить результат. Архив готового сайта сам не обновляется.
Сайт состоит из нескольких связанных файлов. Не передавайте только index.html: нужны также CSS, JavaScript и assets/.
